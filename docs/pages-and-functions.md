# Беттер мен функциялар тізімі

| № | Бет | Функция |
|---|---|---|
| 1 | `index.php` | Жобаның басты беті |
| 2 | `register.php` | Пайдаланушыны тіркеу |
| 3 | `login.php` | Жүйеге кіру |
| 4 | `dashboard.php` | Статистика мен орташа бағаны көрсету |
| 5 | `students.php` | Студент қосу, көру, өңдеу, жою және іздеу |
| 6 | `subjects.php` | Пән қосу, көру, өңдеу және жою |
| 7 | `grades.php` | Баға қосу, көру, өңдеу, жою және іздеу |
| 8 | `logout.php` | Жүйеден қауіпсіз шығу |

## ER-диаграммадағы байланыстар
- `students.id` → `grades.student_id`: бір студенттің бірнеше бағасы болуы мүмкін.
- `subjects.id` → `grades.subject_id`: бір пәнге бірнеше баға тіркелуі мүмкін.
- `users` кестесі аккаунттарды сақтайды; осы бастапқы нұсқада студент жазбаларына тікелей байланыстырылмаған.
