# Студенттердің үлгерімін есепке алу жүйесі

## 1. Жоба туралы
Студенттердің үлгерімін есепке алу жүйесі — студенттер туралы ақпаратты сақтауға, олардың пәндер бойынша бағаларын тіркеуге және оқу үлгерімін бақылауға арналған веб-қосымша.

Жоба PHP, MySQL, HTML, CSS және JavaScript технологияларын пайдалану арқылы әзірленеді.

## 2. Жобаның мақсаты
Студенттердің оқу үлгерімі туралы ақпаратты бір жүйеде сақтау, бағаларды басқару және оқу нәтижелерін ыңғайлы түрде бақылау.

## 3. Негізгі мүмкіндіктері
- Пайдаланушыны тіркеу және жүйеге кіру
- Студенттерді қосу, көру, өңдеу және жою
- Пәндер тізімін басқару
- Студенттердің бағаларын енгізу және басқару
- Студенттің аты-жөні бойынша іздеу
- Пән бойынша сүзу
- Студенттің орташа бағасын есептеу
- Пайдаланушы сессиясын басқару

## 4. Қолданылатын технологиялар
- HTML5, CSS3, JavaScript
- PHP
- MySQL
- PDO
- Git және GitHub

## 5. Негізгі беттер
1. Басты бет — жобаның сипаттамасы
2. Тіркелу беті — жаңа пайдаланушыны тіркеу
3. Кіру беті — жүйеге кіру
4. Басқару панелі — негізгі статистика
5. Студенттер беті — студенттерді басқару
6. Пәндер беті — пәндерді басқару
7. Бағалар беті — бағаларды басқару

## 6. Дерекқор құрылымы
- `users` — пайдаланушылар туралы ақпарат
- `students` — студенттер туралы ақпарат
- `subjects` — пәндер туралы ақпарат
- `grades` — студенттердің бағалары

## 7. Қауіпсіздік
- Құпиясөздерді `password_hash()` арқылы хэштеп сақтау
- Құпиясөзді `password_verify()` арқылы тексеру
- SQL инъекциясынан қорғану үшін PDO prepared statements қолдану
- Енгізілген деректерді тексеру
- HTML-ге шығарылатын деректерді `htmlspecialchars()` арқылы өңдеу
- Жабық беттерге кіруді сессия арқылы қорғау

## 8. Болашақтағы даму
- Үлгерім статистикасын диаграммалармен көрсету
- Бағалар есебін жүктеу
- Пайдаланушылар рөлдерін енгізу
